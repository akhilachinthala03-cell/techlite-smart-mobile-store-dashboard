# TechLite~ Smart Mobile Store Dashboard

A responsive React dashboard for a smart mobile store, built with Vite. The dashboard uses realistic static data and includes sales summaries, an interactive sales chart, top products, and searchable/filterable recent orders.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Pushing to the `main` branch automatically builds and deploys the site to GitHub Pages using GitHub Actions.
